# مسابقة عودة ازدهار

لعبة أسئلة عربية للعائلة، تلعبها الفرق أمام شاشة واحدة (تلفاز، لابتوب، أو جوال).

## طريقة اللعب

1. اختاروا **الفئات** (ثلاث على الأقل)، ثم عدد الفرق وأسماءها، ووقت كل سؤال، وعدد الجولات، والبطاقات المسموحة.
2. في كل جولة يجيب كل فريق عن سؤال واحد بالدور.
3. الفريق صاحب الدور يختار الفئة والصعوبة: سهل ١٠٠، متوسط ٢٠٠، صعب ٣٠٠ نقطة.
4. اختاروا الإجابة ثم اضغطوا الزر البرتقالي للتأكيد قبل انتهاء الوقت.
5. أثناء السؤال تستطيع الفرق الأخرى التخريب من زر **«تخريب»** البرتقالي.
6. صاحب أعلى نقاط بعد آخر جولة يفوز.

## البطاقات (كل فريق يستخدم كل بطاقة مرة واحدة في اللعبة)

### بطاقات المساعدة · يستخدمها الفريق في دوره

| البطاقة | ماذا تفعل |
|---|---|
| وقت إضافي | +١٥ ثانية |
| نقاط مضاعفة | نقاط السؤال ×٢ إن أصبتم |
| حذف إجابتين | تحذف خيارين خاطئين |
| فرصة ثانية | محاولة أخرى إن أخطأتم |
| تغيير السؤال | سؤال آخر من نفس الفئة والصعوبة، ويزول الخلط والضباب والاستعجال |
| الدرع | يمنع التخريب عنكم، ويُبطل الكذبة والخلط والضباب |

### بطاقات التخريب · يستخدمها المنافسون ضد الفريق الذي يجيب

| البطاقة | ماذا تفعل |
|---|---|
| الكذبة | يرى فريقكم الإجابة سراً ويحاول تضليلهم؛ إن أخطأوا تأخذون النقاط |
| الاستعجال | نصف الوقت المتبقي فقط |
| التجميد | لا يستطيعون استخدام بطاقات المساعدة في هذا السؤال (ولا الدرع) |
| الخلط | تتبدل أماكن الإجابات كل ٣ ثوانٍ |
| الضباب | تختفي الإجابات خلف ضباب ينقشع خلال ١٠ ثوانٍ |
| السرقة | عند خطئهم تجيبون أنتم عن نفس السؤال وتأخذون نقاطه |

## التشغيل

لا يحتاج أي تثبيت: افتح `index.html` في المتصفح.
للنشر مجاناً: من إعدادات المستودع في GitHub اختر **Pages** ثم الفرع والمجلد الرئيسي `/`.

## إضافة أسئلة

كل الأسئلة في `assets/questions.js`. كل سؤال سطر بهذا الشكل:

```js
[2, 'نص السؤال؟', 'الإجابة الصحيحة', 'خطأ ١', 'خطأ ٢', 'خطأ ٣'],
```

الرقم الأول هو الصعوبة (1 سهل، 2 متوسط، 3 صعب). الإجابة الصحيحة دائماً أولاً، واللعبة تخلط الترتيب.
لإضافة فئة جديدة انسخ أي فئة وغيّر `id` و`name` والأسئلة.

## ملف الأسئلة (PDF)

[`questions.pdf`](questions.pdf) فيه كل الأسئلة مع إجاباتها الأربع، والإجابة الصحيحة مظللة. يوجد رابط له أيضاً داخل اللعبة في «طريقة اللعب».
بعد إضافة أسئلة جديدة أعيدوا إنشاءه بالأمر `npm run pdf`.

## الاختبارات

اختبارات آلية تلعب اللعبة في متصفح وتتأكد من النقاط والبطاقات والمؤقت والتصميم على الجوال:

```bash
npm install
npx playwright install chromium
npm test
```

بعد إضافة أسئلة جديدة شغّلوا `npm test`: أول اختبار يتأكد أن كل سؤال له ٤ إجابات مختلفة وصعوبة صحيحة.

**English:** a single-screen Arabic family quiz for 2–10 teams. Plain HTML/CSS/JS with no build step: open `index.html`. Questions live in `assets/questions.js` (12 categories, 180 questions). `npm test` runs 35 browser tests covering scoring, every card, the timer, refresh-resume, saves from older versions and phone layouts.
