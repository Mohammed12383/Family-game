# لمّة العائلة

لعبة أسئلة عربية للعائلة، تلعبها الفرق أمام شاشة واحدة (تلفاز، لابتوب، أو جوال).

## طريقة اللعب

1. اختاروا **الفئات** (ثلاث على الأقل)، ثم عدد الفرق وأسماءها، ووقت كل سؤال، وعدد الجولات، والبطاقات المسموحة.
2. في كل جولة يجيب كل فريق عن سؤال واحد بالدور.
3. الفريق صاحب الدور يختار الفئة والصعوبة: سهل ١٠٠، متوسط ٢٠٠، صعب ٣٠٠ نقطة.
4. اختاروا الإجابة ثم اضغطوا الزر البرتقالي للتأكيد قبل انتهاء الوقت.
5. صاحب أعلى نقاط بعد آخر جولة يفوز.

## البطاقات (كل فريق يستخدم كل بطاقة مرة واحدة)

| البطاقة | متى | ماذا تفعل |
|---|---|---|
| وقت إضافي | في دوركم | +١٥ ثانية |
| نقاط مضاعفة | في دوركم | نقاط السؤال ×٢ إن أصبتم |
| حذف إجابتين | في دوركم | تحذف خيارين خاطئين |
| فرصة ثانية | في دوركم | محاولة أخرى إن أخطأتم |
| تغيير السؤال | في دوركم | سؤال آخر من نفس الفئة والصعوبة |
| الدرع | في دوركم | يحميكم من بطاقات المنافسين ويبطل الكذبة |
| الكذبة | دور المنافس | يرى فريقكم الإجابة سراً ويحاول تضليلهم؛ إن أخطأوا تأخذون النقاط |
| الاستعجال | دور المنافس | نصف الوقت المتبقي فقط |
| السرقة | عند خطأ المنافس | تجيبون عن نفس السؤال وتأخذون نقاطه |

## التشغيل

لا يحتاج أي تثبيت: افتح `index.html` في المتصفح.
للنشر مجاناً: من إعدادات المستودع في GitHub اختر **Pages** ثم الفرع والمجلد الرئيسي `/`.

## إضافة أسئلة

كل الأسئلة في `assets/questions.js`. كل سؤال سطر بهذا الشكل:

```js
[2, 'نص السؤال؟', 'الإجابة الصحيحة', 'خطأ ١', 'خطأ ٢', 'خطأ ٣'],
```

الرقم الأول هو الصعوبة (1 سهل، 2 متوسط، 3 صعب). الإجابة الصحيحة دائماً أولاً، واللعبة تخلط الترتيب.
لإضافة فئة جديدة انسخ أي فئة وغيّر `id` و`name` والأسئلة.
